      How to read a query. Cypher draws the pattern you're looking for.
      
      
      

      
        
        
      1. 
          
        MATCH (p:Person)-[:WORKS_ON]->(proj:Project)
        
          
        
            
        Draw the shape
        
            
        Parentheses are nodes, square brackets are relationships, and the arrow gives the direction. This one finds every person who works on a project.
        
            
          
        
        
        2. 
        
      2. 
          
        WHERE proj.status = 'active'
        
          
        
            
        Narrow it
        
            
        Keep only the matches whose properties pass the test. Combine tests with AND, OR and NOT.
        
          
        
        
        3. 
        
      3. 
          
        RETURN p.name AS person, count(proj) AS projects
        
          
        
            
        Say what comes back
        
            
        Return nodes and relationships to draw them. Return properties and counts, as here, to get a table.
        
          
        
        
        4. 
        
      4. 
          
        ORDER BY projects DESC, person
        
          
        
            
        Put it in order
        
            
        Sort the rows, then add LIMIT to cap how many come back.
        
          
        
        
        5.

      What the sample endpoint understands
      
            
      Read-only Cypher: MATCH, WHERE, RETURN, ORDER BY, SKIP and LIMIT, variable-length paths, shortestPath, and the aggregates count, collect, sum, avg, min and max. Anything else needs the live endpoint.
